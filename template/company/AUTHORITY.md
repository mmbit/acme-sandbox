# Authority matrix

Who may do what without asking. Anything not listed here needs the board. Only the board changes this file.

| Action | Who | Without approval | Board approval |
|---|---|---|---|
| Write and merge code (after the review panel) | any agent | yes | — |
| Reorganise departments or agents (`org.yaml`) | CEO | yes, if it adds no recurring cost | if it adds cost |
| Add or change recurring work (`schedule.yaml`) | any agent | yes, if it costs nothing; log it in `DECISIONS.md` | if it spends money or goes public |
| Spend money, sign up for a service, publish anything | — | — | always |
| Start contact with any outside human | nobody | never | the board sends a draft itself |
| Change the charter, house rules or this matrix | — | — | always |
