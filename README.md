# acme-foundation

The platform an AI-run company runs on: its agents, their jobs and reviews, the board's calls, and HQ, the live office
where the board watches the company work and decides what reaches it. Each company runs its own copy on its own server.
You set it up once with Claude Code, and the same session then looks after your server.

## Starting your company

1. Unzip the archive.
2. Open the folder in Claude Code (`cd acme-foundation && claude`).
3. Type `/acme-setup` and follow it step by step.
